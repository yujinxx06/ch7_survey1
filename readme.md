# 📊 생성형 AI 활용 인식 조사 대시보드 (Streamlit)

부산대학교 인문사회계열 1학년 학생들의 생성형 AI 활용 인식을 조사하고 분석하기 위한 Streamlit 기반 대시보드 애플리케이션입니다.

---

```text
ch7_survey/

├── README.md                # 프로젝트 설명서

    ├── 1_데이터_정제.py     # 원본 설문 데이터 정제 및 다운로드

```

## 🛠 주요 기능 및 특징

### 1. Home (`Home.py`)
- 대시보드 전체 소개 및 페이지 이동 가이드 제공

### 2. 데이터 정제 (`pages/1_데이터_정제.py`)
- **CSV 파일 업로드**: 구글 설문지 raw CSV 파일 업로드
- **열 이름 표준화**: 긴 설문 질문 항목을 짧은 형태 (`타임스탬프`, `성별`, `학년`, `소속단과대학`, `AI사용시간`, `Q1~Q6`, `서술형`)로 변경
- **중복 응답 제거**: 타임스탬프를 제외한 모든 컬럼이 동일한 행 중복 제거
- **학년/단과대학 데이터 통일**: 
  - 학년 입력값을 숫자형(`1, 2...`)으로 통일
  - 단과대학 입력을 `인문대학`, `사회과학대학`, `경제통상대학`, `경영대학`, `사범대학`, `기타`로 분류
- **사용시간 변환 및 이상치 처리**: '1시간 30분' 형태의 텍스트를 분 단위 숫자(90)로 자동 변환하고, 사이드바 슬라이더 기준에 맞춰 이상치 제거
- **결측치 처리**: 열별 빈칸 수를 표시하고 사이드바 선택에 따른 '그대로 두기' / '행 삭제' 기능 제공
- **역문항 계산**: 학업 정직성 역문항 점수 변환 ($Q6R = 6 - Q6$)
- **세션 저장 및 다운로드**: 정제 결과를 `st.session_state["clean_df"]`에 저장하고 CSV 다운로드 버튼 제공

### 3. 그래프 분석 (`pages/2_그래프_분석.py`)
- **자동 데이터 연동**: `st.session_state` 내 정제 데이터 활용 또는 정제된 CSV 직접 업로드 지원
- **열 이름 자동 보정**: 컬럼명 불일치에 따른 `KeyError` 방지 logic 내장
- **요약 지표**: 유효 응답 수, 평균 AI 사용 시간, AI 윤리의식 평균 점수 카드 표시
- **정제 전후 비교**: 단과대학별 응답자 수 정제 전후 변화를 가로 막대 그래프로 시각화
- **4가지 상세 분석 탭**:
  1. `응답자 구성`: 성별 및 단과대학 분포
  2. `문항별 평균`: 각 설문 문항의 평균 점수
  3. `집단 비교`: 학년별 및 단과대학별 문항 평균 점수(소수점 둘째자리)와 인원 수 표 작성
  4. `사용 시간과 점수`: AI 사용 시간 대비 선택 문항 점수 간 추이 분석

## 🚀 실행 및 배포 가이드

### 1. 로컬 환경 설치 및 실행
```bash
# 필수 라이브러리 설치
pip install -r requirements.txt

# Streamlit 앱 실행
streamlit run Home.py
```

### 2. Streamlit Cloud 배포 시 주의사항
- GitHub 저장소 최상위 루트 경로에 `Home.py`, `requirements.txt`, `pages/` 폴더가 직접 위치하도록 구성해야 합니다.
- Streamlit Cloud의 **Main file path**를 `Home.py`로 설정하세요.
